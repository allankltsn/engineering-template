# Voltagent

packages.json registra os oito pacotes encontrados na configuração de origem. Estado: configured_not_verified. A lista é uma dependência opcional, não comprova instalação, descoberta ou funcionamento de qualquer agente.

Habilite apenas os pacotes que deseja, usando o gerenciamento de plugins do Claude disponível na sua versão. Não importe permissões de shell da máquina de origem. Os 18 papéis canônicos do template são independentes desses plugins; não substitua silenciosamente um papel por outro com nome parecido. Não há adaptador de instalação Voltagent para Codex neste pacote.
