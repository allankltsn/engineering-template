# Kanban no VS Code

Mescle as chaves de settings.json em .vscode/settings.json; preserve as demais preferências. A extensão Kanban Markdown precisa estar instalada e reconhecer essas chaves. O diretório portátil é docs/sprints/board; ajuste-o explicitamente caso selecione uma sprint. As nove colunas refletem o contrato do workflow, sem a coluna backlog legada. Configuração não comprova renderização do board.
